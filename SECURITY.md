# Security

Keep owner repositories private. Never put private keys, provisioning hashes,
credentials, logs or captures in Git. Commit only public trust certificates.
The signing and evidence environments must restrict deployment to reviewed
protected branches. Do not bypass failed setup or production admission.

Report template vulnerabilities using this repository's private vulnerability
reporting form. Do not include your network configuration or signing material.
For runtime or OS issues, use [Lanrith security reporting](https://github.com/Lanrith/lanrith/security).
